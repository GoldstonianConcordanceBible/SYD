# DESCRIPTION

This introductory course teaches the operational and security steps required to enter the SYD learning/trading environment.

The course prioritizes safe onboarding over blockchain theory.

The learner does not need prior knowledge of:

- crypto,
- blockchain,
- wallets,
- trading.

---

# PREREQUISITES

None.

---

# COURSE LEARNING OUTCOMES

By completion, the learner will be able to:

1. explain the account-to-platform onboarding flow,
2. apply basic account and wallet security practices,
3. distinguish a wallet, network, and platform,
4. explain how funds move between them,
5. identify the actual market instrument shown on the platform,
6. explain how to withdraw funds from the environment.

---
