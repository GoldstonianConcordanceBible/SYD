# LESSON 2 — THE S&P 500

The S&P 500 is a widely followed U.S. equity-market index.

It is used as:

- a benchmark,
- a broad-market reference,
- the basis for multiple financial products.

---

# IMPORTANT

An index measures.

A financial instrument provides exposure.

Those are not automatically the same object.
