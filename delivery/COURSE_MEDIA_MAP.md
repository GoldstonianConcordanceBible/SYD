# COURSE → MEDIA MAPPING STANDARD

## PURPOSE

Each lesson can use existing media, new media, or both.

---

# MAPPING FORMAT

# MAPPING RULE

A video may support more than one course.

Do not duplicate the video.

Reference the same Media ID from multiple courses.

---

# ONE-TO-MANY

↓
