# DELIVERY ROLES

## YOUTUBE

Primary video repository.

Stores:

- historical lectures,
- long-form classes,
- demonstrations,
- short-form clips,
- applied market videos,
- playlists.

---

## SHOPIFY

Direct-to-learner commercial and delivery hub.

Can contain:

- course product page,
- module pages,
- embedded videos,
- readings,
- assignments,
- downloads,
- links,
- access instructions.

---

## GITHUB

Academic and provenance system of record.

Stores:

- course architecture,
- syllabus,
- outcomes,
- lesson map,
- media map,
- assessments,
- rubrics,
- versions,
- evidence,
- revision history.

---

# THE DIVISION OF LABOR

YouTube hosts the media.

Shopify delivers the learner experience.

GitHub documents the curriculum.

SYD controls the academic architecture.

---

# UNIVERSITY FUTURE

A future university should not have to adopt Shopify or YouTube in order to license the curriculum.

The same course package should eventually be portable into:

- Canvas,
- Blackboard,
- Moodle,
- D2L Brightspace,
- another institutional LMS.

Therefore:

## CONTENT MUST BE SEPARABLE FROM DELIVERY PLATFORM.
