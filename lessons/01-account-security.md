# LESSON 1 — ACCOUNT SECURITY

## Before Money Moves, Secure the Account

Minimum practices:

- unique password,
- 2FA,
- secure recovery method,
- verified website/domain,
- avoid unsolicited links.

---

# TELEGRAM WARNING

A fake Telegram admin may:

- DM first,
- ask for wallet connection,
- ask for seed phrase,
- send a fake contract address.

SYD staff should never need a seed phrase.
