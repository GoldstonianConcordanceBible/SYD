# LESSON 2 — WALLET BASICS

## What Is a Wallet?

A wallet allows a user to interact with blockchain accounts and sign transactions.

---

# PUBLIC ADDRESS

Can generally be shared where appropriate.

---

# PRIVATE KEY

Controls signing authority.

Must remain private.

---

# SEED PHRASE

Recovery secret.

Never submit it as coursework.

---

# CORE RULE

PUBLIC ADDRESS MAY BE SHAREABLE.

PRIVATE KEY / SEED PHRASE NEVER IS.
