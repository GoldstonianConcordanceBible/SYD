# INSTITUTIONAL PACKAGE

A university-ready package should progressively include:

- Student syllabus
- Instructor guide
- Course Learning Outcomes
- Program Learning Outcome mapping
- Modules
- Lecture media
- Readings
- Case studies
- Assignments
- Assessment bank
- Rubrics
- Accessibility materials
- AI-use policy
- Academic-integrity policy
- Laboratory options
- Rights documentation
- Version history
- Learner-evidence schema

---

# PLATFORM PORTABILITY

The institutional curriculum should ultimately be portable to:

- Canvas
- Blackboard
- Moodle
- D2L Brightspace
- another university LMS

# IMPORTANT

- Shopify
- GDex
- Telegram
- THE FLOOR
- $SYD
